# Font

Font ini dipakai oleh `scripts/build.py` dan di-embed (subset) ke dalam SVG di `assets/`.
Semuanya berlisensi [SIL Open Font License 1.1](https://openfontlicense.org) — informasi hak cipta
dan lisensi tersimpan di metadata tiap file font.

| File | Font |
| --- | --- |
| `brico800.woff` | [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque) ExtraBold |
| `work500.woff`, `work700.woff` | [Work Sans](https://fonts.google.com/specimen/Work+Sans) Medium & Bold |
| `mono400.woff`, `mono500.woff` | [DM Mono](https://fonts.google.com/specimen/DM+Mono) Regular & Medium |
